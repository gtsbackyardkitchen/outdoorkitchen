GTS Backyard Kitchen - frontend-only store (HTML + inline CSS + JavaScript)
START: run with Live Server / any local server and open index.html (or double-click index.html in Chrome/Edge).
ADMIN: footer > Admin (or admin-login.html). First time you create a password (min 8 characters).

PRODUCTS: 16 kitchens in js/products.js, one photo each in images/products/<slug>.jpg. PRICES ARE ESTIMATES - edit in js/products.js or Admin > Products.
HERO: 4 slides (text in js/store.js HERO_DEF, or edit in Admin > Hero Slides).
Anything you edit in the admin shows only in your own browser. To publish it to all visitors: Admin > Settings > "Download site-data.js", replace site-data.js in this folder, upload the site again.

STILL DEMO: customer accounts, the admin login, orders and tracking updates are saved in the browser on ONE device. A real backend/database is needed to share them.
