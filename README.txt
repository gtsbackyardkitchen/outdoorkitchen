GTS Backyard Kitchen - frontend-only store (HTML + inline CSS + JavaScript)
START: run with Live Server / any local server and open index.html (or double-click index.html in Chrome/Edge).
ADMIN: footer > Admin (or admin-login.html). First time you create a password (min 8 characters).

YOU ADD YOUR OWN CONTENT IN THE ADMIN:
- Products: add / edit / delete, pictures (as many as you like, click one to make it main), description, features, specs, price, category, featured, unavailable.
- Hero Slides: change the 4 homepage banners (photo, headline, text, button).
- Settings: store name, logo, phone, WhatsApp, email, social links, currency ($, AED, EUR, GBP, NGN).

PUBLISHING YOUR ADMIN CHANGES TO ALL VISITORS (no backend needed):
Admin > Settings > "Download site-data.js", then replace the site-data.js file in this folder with the downloaded one and upload the website again.
Without this step your edits are visible only in your own browser.

STILL DEMO: customer accounts, the admin login, orders and tracking updates are saved in the browser on ONE device. A real backend/database is needed to share them.
Files: 11 HTML pages (CSS inline) + js/ (products.js starter catalogue, store.js, storefront.js, account.js, admin-login.js, admin-dashboard.js) + site-data.js + images/.
Optional: put JPGs in images/products/ (see README there) or images/hero/ instead of uploading in the admin.
